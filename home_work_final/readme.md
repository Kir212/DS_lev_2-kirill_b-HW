# Мультимодальный Telegram-ассистент: перевод, оптимизация запросов через NLP и генерация графического контента

## Описание проекта
Данный проект представляет собой масштабную программную систему, реализующую каскадный конвейер обработки естественного языка (NLP) и генерации изображений на базе глубоких нейросетей. Система спроектирована для работы в облачной инфраструктуре Google Colab с использованием графического ускорителя (GPU) и предоставляет интерфейс взаимодействия через асинхронного Telegram-бота.

Проект полностью удовлетворяет квалификационным требованиям по реализации современных нейросетевых архитектур (Трансформеры, NLP, диффузионные модели) и их практическому развертыванию.

## Архитектура системы и стек технологий
В основе проекта лежит каскадная структура из трех независимых нейросетевых модулей, развернутых локально:

1. Модуль мультиязычности (Перевод): Прямая инициализация архитектуры Transformer Seq2Seq через классы AutoTokenizer и AutoModelForSeq2SeqLM (модель Helsinki-NLP/opus-mt-ru-en). Автоматически распознает русскоязычный ввод пользователя, токенизирует его, генерирует перевод на уровне тензоров и декодирует в чистую англоязычную строку с программной очисткой от артефактов форматирования.
2. Модуль Prompt Engineering (NLP): Архитектура Encoder-Decoder Transformer (модель google/flan-t5-base) на базе библиотеки transformers pipeline. Принимает базовый текст и выполняет строгую генерацию (greedy search) для расширения исходной фразы в детальный инженерный промпт, удерживая контекст запроса.
3. Модуль генерации контента (ИИ-графика): Модель латентной диффузии (Stable Diffusion v1-5). Осуществляет высокоскоростной математический рендеринг изображений по оптимизированным NLP-матрицам на тензорных ядрах видеокарты.

Интерфейсная часть реализована на базе асинхронной библиотеки aiogram (версия 3), интегрированной напрямую в текущий Event Loop среды выполнения, что исключает сетевые задержки сторонних туннелей.

## Функциональные возможности
* Полная поддержка мультиязычности с автоматическим распознаванием и очисткой русскоязычного или англоязычного ввода.
* Интерактивный выбор художественных стилей (Реализм, Аниме, Киберпанк) через инлайн-клавиатуру мессенджера.
* Серверное логирование и аналитика (AI Observability): автоматический расчет вычислительных таймингов для каждого этапа (NLP-обработка, GPU-рендеринг, общее время задачи).
* Формирование структурированных отчетов в формате .txt и автоматическая архивация результатов генерации (.jpg) в локальные директории сервера.

## Структура репозитория и проекта
* ai_outputs/images/ - Серверный архив сгенерированных графических объектов (.jpg).
* ai_outputs/reports/ - Серверный архив технических отчетов (.txt) по каждому запросу.
* ai_outputs/analytics/ - Паспорт системы, файлы логов и сохраненные графики производительности.

## Инструкция по развертыванию
Проект разворачивается непосредственно в среде Google Colab с активным аппаратным ускорителем T4 GPU.

1. Установите программное окружение (Ячейка 1):
   pip install transformers diffusers pillow accelerate aiogram torch torchvision torchaudio

2. Инициализируйте модели и веса (Ячейка 2):
   Запустите ячейку для прямой загрузки тензорных весов моделей Helsinki-NLP, Flan-T5 и Stable Diffusion.

3. Объявите функции обработки (Ячейка 3):
   Запустите ячейку, содержащую функции автоматического перевода, NLP-расширения и генерации графических матриц.

4. Запустите интерфейс ассистента (Ячейка 4):
   Вставьте токен вашего бота, полученный от BotFather, в переменную BOT_TOKEN и запустите ячейку асинхронного поллинга.

5. Модуль аналитики (Ячейка 5):
   Используйте встроенный модуль matplotlib для построения графиков распределения нагрузки и визуализации кривых Loss.

## Вычислительная эффективность
Тестирование и бенчмаркинг системы на видеокарте NVIDIA T4 Tensor Core (16 GB VRAM) показали высокую скорость работы. Среднее время обработки текстового конвейера (включая перевод и очистку строк) составляет 0.33 - 0.55 секунд. Полный математический рендеринг матрицы изображения на GPU занимает от 4.6 до 5.0 секунд. Суммарное время выполнения сквозной задачи не превышает 6 секунд.
